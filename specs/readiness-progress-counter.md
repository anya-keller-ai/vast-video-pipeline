# Точный счётчик прогресса загрузки моделей

## Контекст
Readiness-процент вычислялся по максимальному размеру всех SHA-matched HF-файлов `.incomplete`. Hugging Face Hub 1.32 создаёт отдельный случайно именованный `.incomplete` для каждого процесса загрузки; после остановки старый файл сохраняется, а новый transfer пишет в другой файл. Поэтому большой orphan partial мог перекрывать актуальный меньший файл, и UI застревал на старом проценте.

## Цель
Счётчик `downloadedBytes` и проценты показывают активную передачу, а не наибольший stale partial. Не прерывать работающую загрузку и не считать несвязанные файлы.

## Что изменится
1. `web/backend/readiness.py` — среди model-SHA-matched HF `.incomplete` измерять самый недавно изменённый файл; остальные прямые staging/target candidates сохраняют существующую логику.
2. `web/backend/test_readiness.py` — добавить regression, где старый файл больше нового активного partial, и проверить выбор bytes по mtime.
3. `CONTEXT.md` — записать подтверждённую причину, защитное решение и версию Hugging Face Hub.

## Детали реализации
1. Кандидаты HF partial продолжают фильтроваться по имени источника или SHA модели в текущей model-directory.
2. Для каждого matching `.incomplete` получить размер и `st_mtime_ns`; выбрать размер файла с наибольшим `st_mtime_ns`, а не наибольшим размером.
3. Для обычного staging/target файла сохранить прежнюю проверку и итоговое измерение.
4. Не удалять partials автоматически; при тесте замокать файловую систему и проверить старый большой matching-файл, новый меньший matching-файл и посторонний SHA.
5. Текущий HF transfer не перезапускать ради deploy. Развернуть исправление после завершения transfer; затем проверить health/API/UI.

## Критерии приёмки
- [ ] Больший, но более старый matching `.incomplete` не маскирует размер более свежего активного файла.
- [ ] Partial с чужим SHA не влияет на readiness bytes.
- [ ] Progress API и браузерный progress bar совпадают с выбранным активным partial.
- [ ] Backend/frontend regressions, линтеры, typecheck, build, E2E и `git diff --check` проходят.
- [ ] Новая версия развернута без прерывания model transfer; ComfyUI не перезапускается.
