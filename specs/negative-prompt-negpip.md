# Негативный промт (NegPiP) для H3, H3 Turbo и Pika

Статус: **одобрено Аней (2026-11-12), реализовано** (backend, интерфейс, тесты, нода стоит на сервере). Пробный запуск на GPU с негативом и без пока не выполнен: нужны скачанные веса.

## Цель

В формах H3, H3 Turbo и Pika H3 Flex добавить необязательное поле «Негативный промт»: что убрать из кадра. У H3 нет отдельного негативного входа, поэтому используется NegPiP: слово с отрицательным весом `(фраза:-N)` переворачивает знак внимания и вычитает понятие из результата.

## Внешняя нода

- Репозиторий `hako-mikan/comfyui-minimax-h3-negpip`, commit `f725718b4c597fab92cdb1fe981dfe3544a75665`, один файл `minimax_h3_negpip.py`.
- Лицензия **AGPL-3.0** (принята Аней). Запись в `config/custom-nodes.lock.json` с этим commit, `auto_download=False`, установка только с разрешения Ани и перезапуск ComfyUI тоже.
- Узел `ApplyMiniMaxH3NegPiP`: входы `model`, `clip`, `value_strength` (1.0), `apply_positive_weights` (true), необязательные `block_start/end/stride`, `protect_text_rows`, `measure_attention_mass`. Выходы `model`, `clip`.
- Без этого узла ComfyUI читает `(слово:-1)` как буквальный текст, поэтому **при пустом негативе узел в граф не добавляется**, и графы без негатива остаются как сейчас.

## Поведение

1. Поле «Негативный промт» (текст, пусто по умолчанию) и «Сила» (число, по умолчанию 3, диапазон 0.5–5 по README автора).
2. Backend собирает финальный промт: `<промт> (<негатив>:-<сила>)`. Если в негативе есть запятые, это одна группа (README: 2–4 содержательных слова работают лучше одного).
3. При непустом негативе: `ApplyMiniMaxH3NegPiP` вставляется между загрузкой модели (включая LoRA) и сэмплером, его `clip` идёт в кодирование промта. Параметры узла по умолчанию.
4. Валидация: негатив до 300 символов, без скобок, двоеточий и `@` (чтобы пользователь не ломал синтаксис весов), сила в диапазоне.
5. Время (`@start-end`) не поддерживаем: автор сам пишет, что оно работает «как повезёт».

## Не подтверждено (проверяется на GPU)

- Совместимость узла с нашим графом (INT8-модель, Turbo LoRA, разреженное внимание, референсы). Проверка по `/object_info` и пробный запуск.
- Достаточно ли силы 3. Автор предлагает до −5 и параметр `protect_text_rows`, если эффект инвертируется.
